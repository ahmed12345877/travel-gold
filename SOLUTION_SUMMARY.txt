✅ الحل:
───────
5 خطوات فقط (10-15 دقيقة):

1. احصل على Service Account JSON من Firebase Console
2. أضف Environment Variables (متغيرات البيئة)
3. فعّل Google Cloud Storage API
4. أضف IAM Permissions (الأدوار والصلاحيات)
5. Redeploy التطبيق

📋 الخطوات الموجزة:
───────────────────
1. Firebase Console
   → Project Settings
   → Service Accounts
   → Generate New Private Key

2. Firebase Console / Vercel Dashboard
   → Add Environment Variables:
     • FIREBASE_SERVICE_ACCOUNT_JSON
     • FIREBASE_STORAGE_BUCKET

3. Google Cloud Console
   → Search: "Cloud Storage API"
   → Enable

4. Google Cloud Console
   → IAM & Admin
   → Add Roles: Storage Object Creator, Storage Object Viewer

5. Terminal
   $ firebase deploy
   أو اضغط Redeploy في Firebase/Vercel Console
