🆘 COMMON ISSUES & FIXES
─────────────────────────────────────────────────────────────────────────────

Build fails:
  → pnpm install
  → rm -rf .next
  → pnpm build

Port 3000 in use:
  → PORT=3001 pnpm dev

App won't start after deploy:
  → Check environment variables set
  → Check Node.js version (need 20+)
  → View deployment logs
  → Check npm start command works locally
