# 🔍 Firebase Storage Configuration - Issue Analysis & Solution

## المشكلة
الصور تُحفظ محلياً في `/uploads/gallery/` بدلاً من Firebase Cloud Storage، مما يسبب اختفاء الصور عند إعادة تشغيل التطبيق على Firebase App Hosting.

## السبب الجذري
- ✅ الكود موجود بالفعل ويدعم Firebase Storage
- ❌ لكن `FIREBASE_SERVICE_ACCOUNT_JSON` غير مُفعّل
- ❌ النظام يسقط (Fallback) للتخزين المحلي الـ Ephemeral

## الحل
تفعيل Firebase Storage بشكل صحيح من خلال:

### 1️⃣ إضافة متغيرات البيئة
```
FIREBASE_SERVICE_ACCOUNT_JSON = [ملف JSON من Firebase Console]
FIREBASE_STORAGE_BUCKET = gen-lang-client-0364375301.appspot.com
```

### 2️⃣ تفعيل APIs
- Google Cloud Storage API

### 3️⃣ إضافة IAM Permissions
- Storage Object Creator
- Storage Object Viewer

### 4️⃣ التحقق
- رفع صورة
- التحقق من Firebase Console Storage
- إعادة تشغيل التطبيق والتأكد من بقاء الصورة
