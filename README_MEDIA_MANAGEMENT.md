## 🚀 الخطوات السريعة

### 1. لرفع الصورة الخامسة:
```
1. انتقل إلى: Admin > Hero Admin > Main > الصور
2. ابحث عن: "الصورة المميزة (الصورة الخامسة الرئيسية)"
3. اضغط: "رفع صورة"
4. اختر ملفك
5. معاينة فورية تظهر
6. اضغط: "حفظ التغييرات"
7. ✅ الصورة تظهر في الموقع
```

### 2. لتحسين صور الصفحات الفرعية:
```
1. انتقل إلى: Admin > Hero Admin > الصفحات الفرعية
2. اختر صفحة (About, Services, Contact...)
3. اختر نوع الخلفية: صورة أو فيديو
4. ستظهر واجهة جديدة واضحة
5. اسحب الملف أو انقر للاختيار
6. معاينة محسّنة تظهر
7. اضغط: "حفظ الصفحات الفرعية"
8. ✅ التغييرات تظهر في الموقع
```

### 3. لإدارة بروفايل المالك:
```
1. انتقل إلى: Admin > إدارة الملف الشخصي (جديد)
2. تبويب "الملف الشخصي":
   - اسم: Ahmed Roshdi
   - المسمى: Founder & CEO
   - النبذة: اكتب نبذة تعريفية
   - صورة البروفايل: رفع صورة
   - صورة الخلفية: رفع صورة
3. تبويب "الروابط الاجتماعية":
   - Facebook، Instagram، Twitter، LinkedIn، Email
4. اضغط: "حفظ التغييرات"
5. ✅ البيانات تُحفظ وتظهر في الموقع
```

## 🔍 نصائح مهمة

### ✓ أفضل الممارسات:
- استخدم صور بجودة عالية (2000x1500px أو أعلى)
- استخدم صيغ مضغوطة (JPG بدلاً من BMP)
- تحقق من حجم الملف (أقل من 10MB)
- اختبر الصور على أحجام شاشات مختلفة

### ✗ تجنب:
- ملفات صور كبيرة جداً (قد تبطئ الموقع)
- صور بدقة منخفضة جداً (تبدو ضبابية)
- استخدام صيغ غير مدعومة (TIFF, BMP, ICO)
- نسيان الضغط على "حفظ" (التغييرات لن تُحفظ!)

---

## ❓ الأسئلة الشائعة

**س: كم عدد الصور التي يمكن رفعها؟**
ج: في الوقت الحالي 5 صور (4 في الشبكة + 1 مميزة)

**س: ما صيغ الملفات المدعومة؟**
ج: صور (JPG, PNG, WebP, GIF) وفيديو (MP4, WebM)

**س: ما الحد الأقصى لحجم الملف؟**
ج: 10MB لكل ملف

**س: هل يمكن حذف صورة؟**
ج: نعم، الزر الأحمر "إزالة" يحذفها

**س: متى تظهر التغييرات؟**
ج: فوراً بعد النقر على "حفظ"

**س: أين تُخزّن الصور؟**
ج: في Firebase Storage (السحابة الآمنة)

## 🔧 استكشاف الأخطاء

### مشكلة: الصورة لم تظهر
```
✓ حل:
1. تأكد من النقر على "حفظ"
2. أعد تحديث الصفحة (Ctrl+F5)
3. تحقق من حجم الملف (أقل من 10MB)
4. جرّب صورة أخرى
```

### مشكلة: خطأ "فشل الرفع"
```
✓ حل:
1. تحقق من صيغة الملف
2. تأكد من الاتصال بالإنترنت
3. جرّب ملف أصغر
4. أغلق الصفحات الأخرى
```

### مشكلة: الواجهة بطيئة
```
✓ حل:
1. انتظر اكتمال الرفع السابق
2. تحقق من سرعة الإنترنت
3. أغلق الصفحات الأخرى
4. امسح ذاكرة المتصفح (Cache)
```
